# Oeste News

Local news for Rincón, Aguada, Aguadilla, Añasco and Mayagüez, Puerto Rico. Static site on GitHub Pages.

- `index.html`: the app
- `news.json`: story archive (append-only; powers the calendar)
- `rules.md`: rules the scheduled updates follow
- Pull down (or tap "Updated …") to refresh. When `index.html` changes, also change its `data-build` value so open copies reload the new page.
